When a merged pull request's Eyes baselines couldn't be merged into the target branch (baseline conflicts, a refused or missing merge key, a timeout), the plugin comments on the pull request, which notifies its author and reviewers, and adds the label eyes-baselines-not-merged. The comment says what went wrong and how to fix it. Once a build of the target branch merges the baselines, the comment is updated and the label removed.

Needs the GitHub App or token to have Pull requests: Read and write. Without it, the problem is logged and shown under Manage Jenkins → Applitools setup.
